# AGENTS.md — RepoPulse Engineering & Agent Guide

> **Core Tenet:** *Evidence Before Intelligence* — Your repository has the answers. RepoPulse shows you where they are.

## 1. Project Overview & Mission
RepoPulse is an open-source, evidence-grounded Architecture Cartographer and Documentation Truth Engine. It inspects modern and legacy codebases (JavaScript/TypeScript, Express, Fastify, Mongoose, Prisma, etc.), deterministically constructs a 4-tier C4 architecture knowledge graph, detects documentation drift, and synthesizes behavioral characterization tests.

Every architectural claim, diagram edge, and AI response generated by RepoPulse MUST link to verifiable source files, line spans, and AST token evidence.

---

## 2. Technology Stack & Architecture

- **Runtime:** Node.js 20+ (CommonJS & ESM compatible), TypeScript 5.x.
- **AST Parsing Engine:** `@babel/parser` & `@babel/traverse` with full TypeScript/JSX plugins and `errorRecovery: true`.
- **Module Resolution:** Custom Node.js path resolver with `tsconfig.json` / `jsconfig.json` path alias support.
- **Graph Engine:** Graphology directed multigraph with `@dagrejs/dagre` auto-layouting.
- **Persistence:** Dual-engine Prisma ORM (SQLite for zero-config local CLI; PostgreSQL for team/cloud service).
- **Interface Protocol:** Model Context Protocol (MCP) server over stdio and SSE.
- **Web UI:** React 19 / Next.js with React Flow for interactive C4 visualization.
- **Testing:** Vitest with isolated Node.js worker execution.

|:---|:---|

## 5. Agent Operating Rules & Non-Negotiable Boundaries

When working within or contributing to RepoPulse, all AI agents and developers must strictly adhere to these rules:

1. **Evidence Before Intelligence (Zero Hallucination):**
   - Never assert an architectural fact, endpoint, model field, or dependency relationship without citing an `EvidencePointer` (`filePath`, `startLine`, `endLine`, `astNodeType`).
   - If an architectural detail cannot be proven from AST facts, explicitly return `UNKNOWN / UNVERIFIED`.

2. **Zero Code Execution during Static Analysis:**
   - Under no circumstances may analyzed repository code be executed, `eval`'d, or `require`'d into the scanner process.
   - All code inspection is strictly static through AST parsing.

3. **Mandatory Credential & Secret Scrubbing:**
   - All file contents must pass through the secret redaction filter (`redactor.ts`) before being stored as evidence excerpts or passed to LLM prompts.
   - API keys, private keys, passwords, and `.env` credentials must be replaced with `[REDACTED_SECRET: <TYPE>]`.

4. **Preserve Database Isolation:**
   - Tests must never touch or mutate production or user databases. All tests must use ephemeral in-memory SQLite fixtures (`:memory:` or temporary test files) cleaned up on teardown.

5. **Lifecycle Evidence Pack Discipline:**
   - Every major engineering phase must record its inputs, decisions, and output artifacts in `evidence-pack/stage-X-<name>/`.
